# AutoCare AI

Predicts engine faults from sensor readings (PyTorch, benchmarked against scikit-learn) and explains them with a RAG assistant that answers only from vehicle manuals, cites its sources and flags unsupported sentences.

This Space is deployed automatically from GitHub; see the repository for the code, model card and evaluation results.

Not a substitute for a qualified mechanic.
