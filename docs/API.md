# API

Interactive docs (OpenAPI/Swagger) are generated by FastAPI at **`/api/docs`**. All endpoints are under `/api`, and errors share one shape:

```json
{ "error": "validation_error", "detail": [{ "field": "lub_oil_pressure", "message": "Input should be greater than or equal to 0" }] }
```

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/health` | Liveness, model version, vector-store status, LLM provider, guardrail |
| POST | `/api/predict` | One reading in, prediction out, saved to the database (201) |
| POST | `/api/predict/batch` | CSV upload (≤ 1,000 rows, ≤ 2 MB), per-row predictions or errors |
| GET | `/api/predictions?page=&page_size=&risk_band=` | Paginated history, newest first |
| GET | `/api/predictions/{id}` | One prediction with inputs, drivers and chat messages |
| POST | `/api/diagnose` | Question + optional prediction id → grounded answer with citations |
| GET | `/api/model/metrics` | Model comparison, ROC curve, feature importance |
| GET | `/api/model/info` | Sample readings, sensor ranges, threshold, dataset provenance |

## Examples

```bash
curl -X POST localhost:8000/api/predict -H 'content-type: application/json' -d '{
  "engine_rpm": 426, "lub_oil_pressure": 1.88, "fuel_pressure": 3.72,
  "coolant_pressure": 2.25, "lub_oil_temp": 75.36, "coolant_temp": 77.35 }'
```

## Status codes

`201` created · `400` bad CSV · `404` unknown prediction · `422` validation (names the field) · `429` diagnose rate limit · `503` model not trained, or LLM timeout/unavailable (with `Retry-After`).
